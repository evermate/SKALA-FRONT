# SKALA-FRONT

SKALA 과정에서 진행한 HTML/CSS/JavaScript 실습 결과물을 정리한 저장소입니다. 별도의 빌드 도구나 프레임워크 없이 순수 웹 표준 기술만으로 구현했습니다.

## 디렉토리 구조

| 경로 | 설명 |
| --- | --- |
| `html/` | 실습 페이지 |
| `css/style.css` | 전 페이지가 공유하는 스타일시트 |
| `script/` | 페이지별 기능을 담당하는 JavaScript |
| `media/` | 이미지, 영상 등 정적 리소스 |

## 실행 방법

별도 설치 과정 없이 `html/` 폴더의 원하는 HTML 파일을 브라우저로 열면 바로 확인할 수 있습니다. 전체 구성을 살펴보려면 `html/index.html`부터 시작하는 것을 권장합니다.
